LEVEL UP LIFE
GAMIFIED SELF-IMPROVEMENT & PRODUCTIVITY WEB APPLICATION

Level Up Life is a responsive and interactive web application that transforms self-improvement into a rewarding game. Complete tasks, build habits, earn XP, unlock achievements, and become the legendary version of yourself.

PROJECT OVERVIEW

Level Up Life is a client-side web application developed using HTML, CSS, and JavaScript. The system runs entirely in the browser and does not require a backend database. User data is stored using LocalStorage for persistence across sessions.

The application uses gamification techniques inspired by role-playing games (RPGs) — experience points, levels, achievement badges, and streak systems — to motivate users to accomplish their daily goals and improve their habits and productivity.

GENERAL OBJECTIVE

To design and develop a responsive and interactive self-improvement web application using HTML, CSS, and JavaScript that motivates users to improve productivity and habits through gamification.
